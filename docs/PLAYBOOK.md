# 赛前与比赛当天怎么协作

自动测试流程已在真实鲲鹏节点跑通。服务器主机密钥已确认并更新到本地 `config/known_hosts.local`；Agent 优先复用已有 SSH 会话，会话失效时按用户在当前任务中已授权的方式恢复，不把密码写入文件。依次检查环境、提交基线、查状态、拉日志和登记结果，命令见 README。

## 赛前分工

当前任务负责 CONV，用户另外开的任务分别负责 ZGEMM 和 TRSM。三题都保留可运行的共同基线，目标是把公开用例推进到当前能稳定达到的水平，再整理瓶颈与待试方法。是否达到排行榜前 30%–40%，必须以实际平台成绩确认。

每轮只改变一个主要假设，例如分块尺寸、数据布局、微内核形状或线程分工。由 AI 结合代码与实测硬件信息提出方案，编码后通过超算测量筛选；理论上的改进只作为待验证假设。

## 从基线到下一版

1. **建立当下机器基线。** 读 `docs/BASELINES.md` 与历史记录。初次执行 `new conv C0 --strategy "当前代码基线复测"`，不加 parent，不修改源码；经 `submit`、`status`、`fetch` 后，从 `.runs/conv/C0/benchmark.log` 登记三轮结果，再 `promote conv C0`。Z0/T0 同理，环境和参考库如实填写。历史证据不能替代这一步。
2. **分开尝试。** 各自建立分支，用 `new` 创建不同候选，例如 `C1-alice`、`C1-bob`，都指向 `C0`。在候选 `source/` 目录修改，记录假设与参数。
3. **先验证再测量。** 先做必要的构建和正确性检查，再提交公开用例。错误方案仍要留记录；无需给低影响改动堆砌只验证自身实现的测试。
4. **取回结果。** 用 `status` 恢复查询已有作业，再 `fetch`。保存作业状态与原始日志，通过 `record` 登记实际环境、参考库和重复次数。
5. **比较并复测。** 用 `compare` 查看逐用例变化。wrapper 独立执行至少三轮完整套件，`record --repeats 3` 指这三轮，不是 `TEST_RUNS`。记录这些样本的中位数和波动，注明单轮值是否为 benchmark 内部平均值。边际提升接近波动时，交错重测基线与候选。
6. **推进共同基线。** 约定一人 `promote` 已验证候选。双方同步该基线后再开始下一轮，保留旧版本的记录和本地快照。未证实改善时不晋级。

不要把某一组提速掩盖另一组退化。若多组用例有取舍，说明逐组变化，并依据已确认的官方规则作决定；规则未确认时先保留候选。

## 版本与 Git

| 用途 | 示例 |
| --- | --- |
| 共同基线 | `C0`、`Z0`、`T0` |
| 同轮候选 | `C1-alice`、`C1-bob` |
| 分支 | `conv/c1-alice`、`conv/c1-bob` |
| 晋级后共同起点 | 实际获胜候选 ID；使用正式 `C1` 编号时同时记录来源映射 |

一次实验一个唯一 ID，不覆盖旧实验。晋级前检查共同基线是否已被队友更新；若已变化，先同步并基于新版本重新验证。不要两个人同时覆盖题目目录、强制推送或擅自重写队友历史。

本地工作分支为 `setup/agent-workflow`，已验证成果发布到个人仓库 `abuyabislital987-afk/kunpeng-s2` 的 `main` 分支；`personal` 指向个人仓库，`origin` 保留上游 `Palm0palM/kunpeng-s2`。只提交本任务已完成的文件，不纳入其他任务尚未完成的改动。

Git 中保存最佳题解、实验记录与必要说明；`.runs/` 存放本地候选快照和完整产物。需要两人共享某个候选时，明确交换对应源码及哈希，不依赖被忽略的本地目录自动出现在队友机器上。平台正式提交由用户执行，提交后的分数和时间也补充到版本记录。

## 卡住时怎么继续

- **认证或会话失效：** Agent 按用户在当前任务中已授权的方式恢复连接；`python3 tools/connect.py` 是可选登录辅助工具。暂时无法恢复时，保留候选、假设与待执行命令，完成其余工作，不填入估算的服务器成绩。
- **作业排队或断线：** 继续查已有 job ID，保留待运行状态；避免重复排队。
- **正确性失败：** 保存失败用例与日志，缩小问题或回退候选；禁止放宽校验来通过。
- **性能停滞：** 先排除环境变化与测量波动，再改变优化方向；记录已经尝试过的参数与无效方法，避免重复试错。

比赛当天沿用这套流程：两人集中同一题、同一基线、不同策略；每次有可重复提升就更新共同起点。赛前列出的瓶颈假设可以直接作为当天待办。
