## 判定与记录

- C0 首次运行在编译前因运行器未处理无 CPU 的内存 NUMA 节点失败；已修复并加入回归测试，失败日志保留。
- C1-block 使用 NEON 滑窗复用加载，全部正确，但在同一 NUMA 上比 C0-r1 慢约 19.5%，保留原版。
- C2-b64 将默认输出分块改为 64，全部正确；分配到 NUMA 6，与基线 NUMA 4 不同，不作受控速度结论，也不晋级。
- C3-u1 保留 32 列，尝试单步 kernel 循环；在同一 NUMA 上比 C0-r2 慢约 0.86%，部分用例退步超过 1%，不晋级。
- 当前环境：cn22965、GCC 10.3.1、generic、38 核、单 NUMA、官方内置参考；每组本轮 3 次独立完整套件测量。
- 新候选的本地 UBSan 与输入/输出保护页检查均在 1/4 线程下各通过 418 组。ASan 运行库在本机初始化自旋，没有记为通过。
- 原始日志和作业凭据在 records/evidence/conv-*，候选补丁在 records/patches/conv-*，元数据在 records/experiments/conv。
- 环境工具共 54 项测试通过；官方 benchmark 的原始字节保持不变。
- ZGEMM/TRSM 后续测评由用户另外开的任务负责。本任务最后只运行 CONV。
